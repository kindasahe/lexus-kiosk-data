# Lexus Kiosk Data

Temporary data hosting repository for Lexus kiosk app JSON files used during development and testing.

## Purpose

This repository is used to host app-readable JSON files for the Lexus kiosk app during the testing phase.

## Important

This repository should only contain non-sensitive, approved, public-facing data such as:

- Model year
- Model
- Grade
- Display names
- Public prices
- Public vehicle page URLs
- Public screensaver video URLs
- Legal terms
- CTA labels and actions

Do not upload internal notes, credentials, private SharePoint links, draft data, or non-approved pricing.
